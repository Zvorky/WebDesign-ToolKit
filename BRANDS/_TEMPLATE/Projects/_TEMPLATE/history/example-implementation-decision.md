# Example project decision file (template)

**What this file is:** A single project-level decision record (implementation or design choice scoped to this app).

**Location after copy:** `/BRANDS/{brand}/Projects/{project_name}/history/{objective-name}.md`

**Replace this content with:**

- **Context**
- **Decision**
- **Consequences** for future agent runs on this project

Link it from `HISTORY.md`, then delete this example file.
