# Project DESIGN.md (template)

**What this file is:** Optional project-level design overrides on top of the parent brand `DESIGN.md`.

**Location after copy:** `/BRANDS/{brand}/Projects/{project_name}/DESIGN.md`

**When to keep this file:**

- The project needs a distinct layout family, density, or motion budget
- Marketing vs product surfaces diverge under the same brand
- You must explicitly declare custom rules (required by `AGENTS.md`)

**When to delete it:**

- The project fully inherits the brand `DESIGN.md` with no overrides

**Precedence:** This file > brand `DESIGN.md` > Vercel Guidelines.

**Replace this content with** only the deltas (what changes vs the brand), plus a short note that custom project rules exist.
