# Brandbook (template)

**What this file is:** A text companion to the official brandbook / brand guidelines PDF or Figma kit.

**Location after copy:** `/BRANDS/{brand}/brandbook.md`

**Replace this content with:**

- Where the canonical brandbook lives (path or URL — keep binary assets outside git if needed)
- Logo usage rules (clear space, minimum size, forbidden treatments)
- Voice and tone (formal/casual, vocabulary, languages)
- Photography / illustration direction
- Legal / trademark constraints agents must not violate

**Agent note:** Prefer `DESIGN.md` for layout and UI tokens. Use this file for brand identity and messaging constraints that are not purely visual-system tokens.
