# Brand README (template)

**What this file is:** The human- and agent-facing overview of a single brand context.

**Location after copy:** `/BRANDS/{brand}/README.md`

**Replace this content with:**

- Brand name and short positioning statement
- Primary products / surfaces this toolkit will generate for
- Links to brandbook assets, tone-of-voice notes, and stakeholders
- Pointer to `DESIGN.md` as the visual source of truth
- List of active projects under `Projects/` (names only)

**Agent note:** Agents must load this file together with `DESIGN.md` before generating UI for this brand. Do not mix content from other brands.
