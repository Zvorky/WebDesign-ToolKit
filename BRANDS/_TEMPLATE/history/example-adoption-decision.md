# Example brand decision file (template)

**What this file is:** A single brand-level decision record. One decision per file.

**Location after copy:** `/BRANDS/{brand}/history/{objective-name}.md`

**Replace this content with:**

- **Context:** Why the change was considered
- **Decision:** What was chosen
- **Consequences:** What agents and humans must do differently
- **Date / author** (optional)

After writing a real decision, link it from `HISTORY.md` and delete this example file.
