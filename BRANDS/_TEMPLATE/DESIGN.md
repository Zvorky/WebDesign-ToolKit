# Brand DESIGN.md (template)

**What this file is:** The brand-level visual and interaction guidelines (Stitch / VoltAgent-style plain-text design system).

**Location after copy:** `/BRANDS/{brand}/DESIGN.md`

**Replace this content with sections such as:**

1. Visual theme and atmosphere
2. Color palette and semantic roles (hex + usage)
3. Typography rules and hierarchy
4. Component styling defaults (buttons, inputs, navigation)
5. Layout principles and spacing scale
6. Depth, elevation, and motion preferences
7. Do’s and don’ts / anti-patterns
8. Responsive behavior
9. Explicit statement if this brand defines **custom rules** that override the Vercel Guidelines fallback

**Sources:** You may start from a file in `vendor/awesome-design-md/` or write one from the brandbook.

**Precedence:** Project `DESIGN.md` overrides this file. This file overrides Vercel Guidelines.
