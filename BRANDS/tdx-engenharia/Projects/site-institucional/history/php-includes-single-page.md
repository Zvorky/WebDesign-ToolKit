# Página única PHP com includes

**Data:** 2026-10-01  
**Escopo:** `Projects/site-institucional`

**Decisão:** Servir o marketing site como `index.php` com `includes/header.php` e `includes/footer.php`, CSS/JS estáticos. Sem SPA e sem bundler. Seções âncora para Início, Sobre, Serviços, Conduta e Contato.

**Alternativas rejeitadas:** Next/React (fora do requisito), múltiplas rotas PHP (desnecessário para um institucional de uma página).
