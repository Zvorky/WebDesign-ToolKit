# awesome-design-md — Setup

Curated `DESIGN.md` files extracted from real brand sites (VoltAgent / Stitch-style). No runtime install — copy the file you need.

## Install / clone (optional reference)

```bash
git clone https://github.com/VoltAgent/awesome-design-md.git
```

Or browse the collection online without cloning: https://getdesign.md/

## Use in this toolkit

1. Pick a brand’s `DESIGN.md` from the collection.
2. Copy it into the target brand context: `/BRANDS/{brand}/DESIGN.md`.
3. Tell the agent to follow that file for look and feel.
4. Prefer brand/project `DESIGN.md` over any shared fallback.

Do not commit brand-specific copies into the shared repo; `/BRANDS/` is git-ignored.

## Verify

Open the copied `DESIGN.md` and confirm color roles, typography, and layout rules are present before generating UI.
